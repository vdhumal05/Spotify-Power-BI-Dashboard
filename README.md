# 🎵 Spotify Top 50 Dashboard – Power BI Project

I) Project Overview
This project analyzes Spotify Top 50 dataset using Power BI to extract insights about song popularity, artists, album types, explicit content, and monthly trends.

 II) Key Features
- Total Songs KPI
- Distinct Artists Count
- Average Popularity
- Explicit vs Non-Explicit Analysis
- Songs by Album Type
- Monthly Trend Analysis
- Image-based Song Selector (Album Covers)

III) Tools Used
- Power BI
- DAX
- Data Cleaning
- Image URL Handling

IV)Insights
- Most songs are non-explicit
- Album releases dominate over singles
- Popularity varies significantly by month
